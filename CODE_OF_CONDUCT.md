# Code of Conduct

Nfinit uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful in issues, pull requests, and discussions. Give feedback about the work, not the person. Harassment, insults, and personal attacks are not accepted.

## Reporting

Email **muayyad.shahid1@gmail.com** to report a problem. The maintainer reads each report, keeps the reporter's identity private, and can remove comments, close threads, or block accounts that break this code.
